Ligone Launcher

Лаунчер Minecraft с офлайн-входом и Ely.by, инстансами, браузером модов Modrinth и CurseForge и автоматическим подбором Java. Лёгкий десктоп на Tauri 2.

⬇ Скачать Возможности
Фронтенд: React 19 + TypeScript (Vite) Бэкенд: Rust Оболочка: Tauri 2

Возможности

Всё для комфортной игры — от аккаунтов до модов и запуска.

👤

Аккаунты

Офлайн-вход (UUID как nameUUIDFromBytes в Java) и Ely.by — OAuth (рекомендуется) или вход по паролю. Аккаунты сохраняются, токены Ely.by — в OS keyring (Windows Credential Manager), на диске секретов нет.

📦

Инстансы

Создание, переименование и удаление. Скачивание выбранной версии Minecraft и Fabric (jar, библиотеки, ассеты) с проверкой по sha1 — валидные файлы не скачиваются повторно. У каждого инстанса свои mods/, resourcepacks/, shaderpacks/, saves/.

🧩

Браузер контента

Поиск и установка модов и ресурспаков с Modrinth и CurseForge. Всегда фильтр по версии игры, для Fabric — по загрузчику. Зависимости модов ставятся автоматически. CurseForge — при наличии CURSEFORGE_API_KEY, иначе только Modrinth.

☕

Автоподбор Java

Пользовательский путь → рантайм Mojang (скачивается без UAC/MSI) → системная Java. Нужная версия подбирается автоматически.

🚀

Запуск игры

JVM-аргументы, распаковка нативных библиотек, authlib-injector — скины по нику работают и офлайн. Лог пишется в <инстанс>/launcher.log, при аварийном выходе ошибка показывается в UI.

🎨

Интерфейс

Тёмная и светлая темы, русский и английский языки. Аккуратный десктопный UI на React.

Как начать

Скачайте установщик лаунчера, запустите его и настройте Ely.by для входа через этот сервис.

Скачайте установщик

Нажмите кнопку «Скачать» — файл ligone-launcher_0.1.0_x64-setup.exe загрузится на ваш компьютер.

Запустите

Откройте ligone-launcher_0.1.0_x64-setup.exe и следуйте инструкциям установщика.

Настройте Ely.by

Для OAuth/парольного входа укажите ELYBY_CLIENT_ID и ELYBY_CLIENT_SECRET в %APPDATA%\.ligone\.env или переменных окружения.

Для release-сборки: Redirect URI для OAuth — http://localhost:8921/ely/callback (в dev — http://localhost:1420/ely/callback). Его нужно зарегистрировать в приложении Ely.by и при необходимости задать ELYBY_REDIRECT_URI. Переменные окружения имеют приоритет над .env, секреты нигде не хардкодятся.
