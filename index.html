Ligone Launcher

Лаунчер Minecraft с офлайн-входом и Ely.by, инстансами, поддержкой Fabric и Forge, а также браузером модов, ресурспаков и шейдеров с Modrinth и CurseForge.

⬇ Скачать Возможности
Фронтенд: React 19 + TypeScript (Vite) Бэкенд: Rust Оболочка: Tauri 2

Возможности

Всё для комфортной игры — от аккаунтов до модов, шейдеров и запуска.

👤

Аккаунты

Офлайн-вход (UUID как nameUUIDFromBytes в Java) и Ely.by — OAuth (рекомендуется) или вход по паролю. Ely.by работает из коробки, без настройки. Аккаунты сохраняются, токены — в OS keyring (Windows Credential Manager), на диске секретов нет.

📦

Инстансы

Создание, переименование и удаление. Скачивание выбранной версии Minecraft с vanilla, Fabric или Forge (jar, библиотеки, ассеты) с проверкой по sha1 — валидные файлы не скачиваются повторно. Forge ставится через официальный установщик (1.13+; для 26.1+ Forge не существует — лаунчер предупредит). У каждого инстанса свои mods/, resourcepacks/, shaderpacks/, saves/.

🧩

Браузер контента

Поиск и установка модов, ресурспаков и шейдерпаков с Modrinth и CurseForge. Всегда фильтр по версии игры, для модов — ещё и по загрузчику (Fabric/Forge). Зависимости модов ставятся автоматически. CurseForge требует CURSEFORGE_API_KEY, без ключа доступен только Modrinth.

☕

Автоподбор Java

Пользовательский путь → рантайм Mojang (скачивается без UAC/MSI) → системная Java. Нужная версия подбирается автоматически.

🚀

Запуск игры

JVM-аргументы, распаковка нативных библиотек, authlib-injector — скины по нику работают и офлайн. Лог пишется в <инстанс>/launcher.log, при аварийном выходе ошибка показывается в UI.

🎨

Интерфейс

Тёмная и светлая темы, русский и английский языки. Аккуратный десктопный UI на React.

Как начать

Скачайте установщик, запустите его — и можно играть. Ely.by уже настроен.

Скачайте установщик

Нажмите кнопку «Скачать» — файл ligone-launcher_x64-setup.exe загрузится на ваш компьютер.

Установите и запустите

Откройте ligone-launcher_x64-setup.exe, следуйте инструкциям установщика и запустите лаунчер.

Войдите и играйте

Выберите офлайн-аккаунт или Ely.by (работает сразу), создайте инстанс с нужной версией и запускайте игру.

Важно: готовые сборки также лежат на вкладке Releases в GitHub. Для CurseForge нужен CURSEFORGE_API_KEY, без него поиск работает только через Modrinth. Forge недоступен для версий 26.1+ — лаунчер предупредит при создании такого инстанса.
